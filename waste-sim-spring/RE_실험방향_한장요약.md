# R&E 한 장 요약 — 엣지 AI 발열·냉각 가성비 연구

**핵심 질문(발표 필수 답변):** *"왜 이걸 해야 하나?"* → **지속가능성(SDGs).**
최고 냉각은 비용 과다 → **성능을 조금 낮춰도 비용을 크게 줄이는 적정점**을 찾는다.
평가 기준: **"면적 절반(비용 절반)인데 냉각 효율 80% 유지면 가성비 좋다."**

```
AI 데이터센터 발열 → 스로틀링(성능 저하) → 냉각 필요
→ 최고 냉각 = 비용 과다 → 냉각 조금 낮추고 비용 크게 줄이는 방법
```

### 실험 3종 · 우선순위 (교수님: **3번 폐쇄구조 먼저 → 그 안에서 1번**)

| # | 실험 | 통제 | 판정 |
|---|---|---|---|
| **1** | 방열판 **면적·분할**(통짜 vs 조각) | 표면적 동일 | 차이 크면 통짜, 비슷하면 발열지점에만 조각 |
| **2** | **TIM**(그리스·카본·그래핀, 양·도포법) | 나머지 전부 | PC 튜닝 커뮤니티 선행연구 많음 |
| **3** | 냉각 **위치**(팬 유무·개수·배치) | 폐쇄 구조 | 데이터센터식 능동 냉각 |

**측정:** 열화상 스팟 ↔ 내부온도 페어 · 24℃ 냉각 후 시작 · 1~2초 간격 80℃까지 · **30회 반복**(평균±표준오차)

### 미팅 논점 ↔ 시뮬레이터 (✅구현 / ❌미구현)

- **✅ ① 온도 출렁임 = 스로틀링**(부하 아님). 태스크 8초 ≪ τ 58~98초라 열용량이 평균해버림 → 진동은 **거버너 히스테리시스**. 모델 예측: 30분 37회·TED 14초. **니크롬선 교체 불필요.**
- **✅ ③ 온도 진폭 지표** = `HeatsinkMass`(2노드). 방열판 질량이 피크 흡수 → **열저항 나쁜 작은 방열판이 역전 가능** = 1번 실험의 물리 근거.
- **🔶 ② 예측냉각(PTM)** — 부하패턴·열모델 있음, **제어기만 남음**.
- **🔶 ④ 열화상 vs 내부 간극** = `P × R_jc` → 실측으로 **R_jc 역산**, 2노드 내부저항으로 모델 검증.

### ⭐ 핵심 미해결 — 팬 전력이 모델에 없다

팬 역할 셋: ①냉각(6.5→3.9→**2.6 K/W**) · **②비용(RPM↑=전기세, 교수님 첫 지적)** · ③PTM 액추에이터.
현재 전력 = SoC만(`idle + dyn×util×clock`), **팬 전력 없음** → "가성비 최적"을 물으면 **항상 팬 최대**(비용 0).

**필요:** `P_총 = P_SoC + P_팬(∝RPM³)`. RPM 2배 → 전력 8배, 냉각은 완만 → **"적정에서 멈춤"의 물리 근거.**
답할 질문: *스로틀링을 막으면서 **총 전력 최소**가 되는 RPM은?* (= 지속가능성 결론 = PTM 목표함수)
