포항시 장량동의 생활쓰레기 수거 시뮬레이터를 만들어줘. 수거 차량이 도는 시각을 바꿔가며 주민 민원이 얼마나 줄어드는지 보고 싶어.

② 돌아온 것 — 실행되는 코드

def simulate_waste_collection(collection_time,
                              total_residents=1000,
                              initial_complaints_rate=0.1):
    initial_complaints = int(total_residents * initial_complaints_rate)

    if collection_time < 8:
        complaint_reduction_rate = 0.5
    elif 8 <= collection_time < 18:
        complaint_reduction_rate = 0.2
    else:
        complaint_reduction_rate = 0.1

    return int(initial_complaints * (1 - complaint_reduction_rate))

collection_times = [6, 8, 12, 18, 20]
붉은 값이 모델이 스스로 정한 숫자다.
