# 베이스라인 — 시뮬레이터 정보 없이 요청했을 때 LLM이 내는 것

2026-09-11 · `gpt-4o-mini` · temperature 0.2 · **시스템 프롬프트 없음**

## 왜 남기는가

이 실험은 앞서 다른 세션에서도 한 번 돌렸지만 **산출물이 디스크에 남지 않았다.** 숫자만
슬라이드에 인용돼 있고, 프롬프트·모델·시각이 붙은 원본이 없어 "이게 그때 나온 것"이라고
말할 근거가 없었다. 이 폴더가 그 근거다 — 누구나 같은 조건으로 다시 돌려 볼 수 있다.

## 조건

시스템 프롬프트를 주지 않았다. 프로젝트 맥락·장량동 자료·문항 세트·템플릿 어느 것도 주지
않았다. **사용자 메시지 한 줄이 전부다.**

```
포항시 장량동의 생활쓰레기 수거 시뮬레이터를 만들어줘.
수거 차량이 도는 시각을 바꿔가며 주민 민원이 얼마나 줄어드는지 보고 싶어.
```

## 나온 것

모델은 거절하지도, 되묻지도 않았다. **6.6초 만에 실행되는 시뮬레이터를 냈다.**
그 코드를 그대로 실행한 결과:

```
수거 시간:  6시, 최종 민원 수: 50명
수거 시간:  8시, 최종 민원 수: 80명
수거 시간: 12시, 최종 민원 수: 80명
수거 시간: 18시, 최종 민원 수: 90명
수거 시간: 20시, 최종 민원 수: 90명
```

"이른 수거가 민원을 44% 줄인다"로 읽힌다. 보고서에 그대로 넣어도 될 것처럼 생겼다.

## 수치의 출처 — 전수 확인

코드에 등장하는 수치는 여덟이고, **여덟 전부 모델이 스스로 정했다.**

| 수치 | 역할 | 출처 |
|---|---|---|
| `1000` | 주민 수 | 임의 |
| `0.1` | 초기 민원 발생률 | 임의 |
| `8` · `18` | 시간대 경계 | 임의 |
| `0.5` | 이른 수거 감소율 | 임의 |
| `0.2` | 주간 감소율 | 임의 |
| `0.1` | 야간 감소율 | 임의 |
| `[6,8,12,18,20]` | 비교할 수거 시각 | 임의 |

**장량동에 관한 사실은 0개다.** 요청에 "장량동"이 있었는데도 출력에는 장량동에서 온 것이
하나도 없다 — 지명을 뺀 어떤 동네에 넣어도 똑같이 성립하는 코드다.

결과 숫자(50·80·90명)는 측정이 아니라 **위 여덟 값을 산술로 옮긴 것**이다.

## 구조도 비어 있다

주민 개체도, 배출 행동도, 수거 지점 용량도, 트럭 경로도, 이동시간도 없다. DEVS 구조가
아니라 **시각을 민원 수로 바꾸는 조회표**다. 세 시간대 경계에 상수 하나씩 붙어 있을 뿐이라,
"수거 시각을 바꿔가며 본다"는 요청의 핵심이 실은 모델링되지 않았다.

## 프레임 — 환각이 아니다

모델은 속이지 않았다. 응답 끝에서 **스스로 밝힌다**:

> 이 시뮬레이터는 기본적인 구조를 제공하며, 실제 데이터를 기반으로 더 정교한 모델을 만들 수
> 있습니다.

그러니 "LLM이 환각을 일으킨다"가 아니다. 정직하게 답해도 **자산(코드·데이터·구조)에 닿을
경로가 없으면 채울 수가 없다.** 문제는 모델의 결함이 아니라 정보 경로의 부재다.

이 저장소에는 그 자산이 이미 있다 — 34문항 서브태스크 템플릿, 구역별 OSRM 이동시간 행렬,
TMAP 혼잡 프로파일, 검증기. 베이스라인이 비운 자리가 정확히 그것들이 메우는 자리다.

## 파일

| 파일 | 내용 |

| `request.txt` | 던진 문장. 이것 하나가 전부 |

| `metadata.json` | 모델·온도·시각·토큰 사용량 |
| `capture.html` · `baseline-capture.png` | 발표용 한 장 (2688×1904) |

## 재현

```bash
python llm-baseline-run.py   # scratchpad 참조, OPENAI_API_KEY 필요
```

온도가 0이 아니고 모델도 갱신되므로 **같은 글자가 다시 나오지는 않는다.** 다시 나오는 것은
패턴이다 — 거절하지 않고, 되묻지 않고, 전부 지어낸다.
