추가 계약: T2-tree 구성 복원
g 단계의 상위 구성 후보와 b2 상태 개체를 함께 연결한다. 상태 없는 상위 개체도 허용하지만,
구성 후보의 식별·조립 근거가 필요하다. 이름 목록은 형식 조건을 갖춘 후보이며 의미 승인 목록이 아니다.
분해마다 evidence와 member_evidence를 요구한다. member_evidence는 자식 이름을 키로,
그 부모-자식 관계를 뒷받침하는 인용 배열을 값으로 갖는다. 이미 존재하는 자식에도 필요하다.
ASPECT는 부분 구성, SPEC은 하위 유형과 선택 범위(selection),
MULTI는 반복 인스턴스와 multiplicity.evidence(개수/범위)를 입증한다.
ASPECT 자식을 이 단계에서 새로 만들지 않는다. 누락 구성 개체는 disputes에 기록한다.
단순 호출·시간 순서·값 전달을 포함 관계로 쓰지 않는다. 결합은 별도 그래프로 남긴다.
트리 완성을 위해 관측값·상태 속성을 개체로 올리지 않는다.
근거 있는 간선만 제안한다. 단일 부모·비순환·전체 도달을 목표로 하되,
연결 불명은 보류하고 unknown 활성을 항상 활성으로 바꾸지 않는다.
