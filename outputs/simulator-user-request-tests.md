# 시뮬레이터 MCP 사용자 요청 테스트 목록

작성일: 2026-10-28. 대상: 브로커 및 장량동 폐기물·행정동 폐기물·공영주차장·민원 창구 서버.

이 문서는 수동 인수 테스트 계획이다. 아래 요청을 실제로 실행했다는 의미가 아니며 모든 결과는 미실행 상태다. 기대 동작은 능력 카드와 입력 검증 코드를 기준으로 한다. 코드와 명세가 다르면 결함 또는 명세 불일치로 기록한다.

## 1. 테스트 방법과 공통 합격 기준

- 독립 사례는 새 대화에서 시작한다. 후속 대화 사례는 같은 대화에서 이어서 입력한다.
- 정상 사례에서도 필요한 추가 질문에는 답하고, 제안된 전체 설정을 검토한 후 확인 화면에서 승인한다. 최초 요청만으로 무조건 바로 실행되는 것을 합격으로 보지 않는다.
- 누락값 사례는 해당 값을 끝까지 주지 않은 상태에서 실행이 차단되는지 먼저 확인한다. 이후 값을 제공하고 정상 흐름으로 복구되는지 확인한다.
- 비교 사례는 비교 변수 외의 설정을 같게 유지한다. 최종 설정에서 비교 대상이 실제로 다른지 확인한다.
- 기본 기능 확인은 짧은 기간과 1~3회 반복으로 진행한다. 결과 비교 검증은 공통 난수 조건과 충분한 반복을 사용한다. 특정 정책이 반드시 개선된다는 방향성을 합격 기준으로 삼지 않는다.
- 오류는 사용자에게 원인·문제 필드·수정 방법을 설명해야 한다. 인증키나 전체 인증 URL을 출력하면 실패다.
- 지원 불가 사례는 불가능한 결과를 만들어 내지 않고 이유와 가능한 대안을 설명하면 합격이다. 실제 거절도 정상 동작이다.
- 오류를 피해 값을 임의 보정하거나, API 실패를 가정 데이터로 조용히 바꾸거나, 승인을 대신하면 실패다.
- 로그에서 서버·도구·검증 결과를 확인하고, 설정·결과·출처를 함께 보관한다.

서버 포트: 브로커 8089 / 장량동 8090 / 행정동 8091 / 주차장 8092 / 민원 창구 8093.

## 8. 숫자 경계값 테스트

각 행은 최솟값-1, 최솟값, 최댓값, 최댓값+1을 각각 독립 사례로 수행한다. 다른 값은 정상 조건으로 두며, 경계값 자체가 유효해도 조합 과부하로 차단될 수 있다. 최대값 여러 개를 동시에 적용해 대규모 실행하지 않는다. 상한 검증만 필요한 경우 시나리오 검증 단계에서 멈춘다.

| 모델 | 항목 | 유효 범위 |
|---|---|---|
| 장량동 | 건물 수 / 기간 / 반복 | 1~26 / 1~365일 / 1~100회 |
| 장량동 | 수거 시각 / 배차 간격 | 0~1439분 |
| 장량동 | 주민 수·차량 수 / 수거장 용량 | 각각 1 이상 / 0 초과; 임의 상한을 만들지 않음 |
| 장량동 | 민원 임계 / 경로 가용 적재량 | 0~1 / 0 초과이면서 차종 정격 이하 |
| 행정동 | 구역 / 구역당 가구 / 차량 | 1~40 / 50~5000 / 1~20 |
| 행정동 | 기간 / 반복 / 수거 시작 | 7~365일 / 1~100회 / 0~1439분 |
| 행정동 | 근무시간 / 적환장 왕복시간 | 카드상 120~720분 / 10~300분; 검증 경로 일치 확인 |
| 창구 | 창구 / 하루 방문객 / 평균 처리 | 1~20 / 1~5000 / 1~60분 |
| 창구 | 최대 대기 / 예약 비율 | 1~240분 / 0~1 |
| 창구 | 기간 / 반복 | 1~60일 / 1~100회 |
| 주차 | 시설 수 / 가정 시설당 면수 | 1~12 / 10~1000 |
| 주차 API | 시설별 총면수 / 잔여면수 | 1~10000 / 0~총면수 |
| 주차 API | 기존 차량 잔여 체류 | 1~1440분 |

| 주차 | 할증률 / 거주자 우선 비율 | 0~3 / 0~0.9; 스냅샷에서는 우선 비율 0 |
| 주차 | 기간 / 반복 | 1~90일 / 1~100회 |

선택형 항목에는 알 수 없는 문자열, 숫자에는 음수·빈 값·숫자가 아닌 값, 필수 목록에는 빈 목록도 입력한다. 30%와 0.3, 6시와 360분 등 단위 변환도 최종 설정에서 확인한다.

## 10. 우선 실행 순서와 기록 양식

빠른 1차 점검: B02, B03, B04, B05 → J01, D01, C01, P01 → C09, P06 → A01, A04, A07, A08 → B10, B12 → O06, O07.
